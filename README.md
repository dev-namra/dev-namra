### 🚀 About Me

I started out as a trained **architect** — five years of architectural education and three years designing buildings in Delhi — before pivoting into **BIM Project Management** (MSc, Queen's University Belfast) and then teaching myself to build the software that BIM teams actually run on.

- 🏗️ Background in architectural design, now specializing in **BIM & Digital Construction**
- 🧠 Built a full-stack **BIM data management platform** for a construction firm — integrated with Autodesk Platform Services (APS) and a Common Data Environment (CDE) — as sole developer, from spec to production
- 📈 The platform reached **62+ active users** and delivered **~£15,000 in projected annual licensing savings**
- 🔧 Comfortable across the stack: **Revit API / C#** on the BIM side, **React, TypeScript, Node.js** on the web side
- 🎯 Interested in where **digital twins, ISO 19650 workflows, and clash detection** meet good software engineering
- 📫 Reach me at: **mahaknamra@outlook.com**
- 🌐 Portfolio: [dev-namra.github.io](https://dev-namra.github.io/namramahak/)
